# 自媒体中控台 · 使用说明

一个只在自己电脑上跑的自媒体数据分析工具。
数据和登录态默认保存在本机。启用 AI 功能时，相关账号信息、作品标题和指标会发送给所配置的模型服务商（默认 DeepSeek）。

---

## 一、先装运行环境（只装一次）

### macOS

1. 打开 https://nodejs.org
2. 下载 **LTS** 版本，一路「继续 / 同意 / 安装」
3. 装完继续看下面第二步

### Windows

1. 同样打开 https://nodejs.org
2. 下载 **LTS** 的 Windows 安装包（.msi），一路下一步
3. 装完**重启一次电脑**

> 没装 Node 就双击安装脚本，它会提示你去哪下载，不会报错卡住。

---

## 二、安装并启动

### macOS

双击 **`1-安装并启动.command`**

> 如果提示「无法打开，因为来自身份不明的开发者」：
> **右键点它 → 打开 → 再点「打开」**。每次更新版本都要这么做一次，
> 这是 macOS 对未签名脚本的限制，不是文件有问题。

### Windows

双击 **`1-安装并启动.bat`**

> 如果 SmartScreen 弹出警告：点「更多信息」→「仍要运行」。

第一次会自动装依赖 + 构建，大约 3 分钟，别关窗口。

跑完浏览器会自动打开配置页。

---

## 三、四步配置

打开 http://127.0.0.1:3300/setup 会看到四步：

### 1. 填 DeepSeek API Key

去 https://platform.deepseek.com 注册，在「API Keys」里新建一个，复制粘贴进来。

- 没有 Key 也能用，只是不出 AI 建议（规则预警照常）
- Key 只存在你自己电脑的 \`app/.env.local\` 里
- 费用很低：一次完整复盘约 0.01 元

### 2. 扫码登录抖音

点「弹出登录窗口」，会弹出一个浏览器，用抖音 App 扫二维码。

- 登录态只存在你电脑里（\`app/../.data/profiles\`）
- 不会上传，工具也拿不到你的密码
- 大约几周会过期一次，过期了重新点这个按钮即可

### 3. 采集第一批数据

点「开始采集」，等 30 秒。采完打开「总览」就有数据了。

### 4. ffmpeg（可选）

装了才算得出「镜头节奏」。macOS 装法：\`brew install ffmpeg\`。
不装不影响其他功能。

---

## 四、之后怎么用

**日常看数据**：双击 `1-安装并启动.command`，打开 http://127.0.0.1:3300

**让它自动更新**：双击 `2-启动监控.command`。

在「监控」页的「同步与打扰设置」里，分别为作品、私信和爆款雷达选择手动、每小时、每 6 小时或每天。默认抖音和闲鱼仅手动，小红书每 6 小时。可分别手动同步作品、私信和扫描爆款。

抖音和闲鱼采集仍可能短暂出现浏览器窗口，登录需要可见窗口。监控每分钟检查队列，任务会依次运行。模型复盘默认每天运行。

日志在 `.data/watcher.log`。

要停止：双击 `3-停止监控.command`。

**开机自动跑（推荐）**：把 `4-开机自启.command` 加进「系统设置 → 通用 → 登录项」。

它会把「网页服务 + 监控」一起拉到后台，窗口闪一下就关。
以后开机 → 打开浏览器输入 `http://127.0.0.1:3300` 就能直接用。

> 只加 `2-启动监控.command` 是不够的：那个只同步数据，不开网页服务。

## 五、常见问题

**Q：会封号吗？**
A：工具只读自己的数据，单并发、限速、不开无头浏览器，不做点赞评论关注。
但它确实是用你自己的身份访问抖音网页，风险不为零。建议低频使用。

**Q：数据传到哪里了？**
A：哪里都没传。全部在你电脑的 \`.data\` 目录里，删掉就等于清空。

**Q：能同时管多个账号吗？**
A：当前版本一个抖音账号。多账号以后再说。

**Q：Windows 能用吗？**
A：能，但没在 Windows 上充分测试过。遇到问题把报错截图发出来。

**Q：为什么每次更新都要重新双击安装？**
A：因为要重新构建。改动不频繁的话，平时直接用 `2-启动监控.command` 就行。

## 数据备份

在「监控」页点击「创建本地备份」，保存 SQLite 数据库快照到项目数据目录的 backups 文件夹。备份包含作品、指标与收件箱，不包含浏览器登录态和 API Key。恢复前请停止网页和监控并保留当前数据库副本；本版本没有自动恢复功能。
